# Ecommerce Platform

Production-oriented e-commerce platform built with Django, React, PostgreSQL, Redis, RabbitMQ, Celery and real-time WebSocket chat.

## Stack

### Backend
- Django 5.2.9
- Django REST Framework
- Django Channels
- PostgreSQL
- Redis
- RabbitMQ
- Celery

### Frontend
- React
- TypeScript
- Vite
